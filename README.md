## 操作・UI仕様

- **白い背景のメインメニューハブ（`#menu-hub`）**: 初回起動時に2作品をカード＆ボタンで選択可能。作品鑑賞中も右上の **`⌂` ボタン** または `Esc` キーでいつでもメインメニューへ戻って別作品へ切り替えられます。
- **スマホ横画面・自動全画面対応**: メニューの再生ボタン押下時に Fullscreen API ＋ `screen.orientation.lock('landscape')` を自動試行。
- **極限ミニマリスト再生UI**: 再生中は自動でHUDが消灯し、画面タップまたはマウス移動時のみシークバーと操作アイコンが表示されます。

```bash
npm install
npm run dev
npm run build
```
