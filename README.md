## 独自開発・6大超絶最適化技術（[src/optimizer.js](./src/optimizer.js)）

1. **GAK-Instancer（GPU解析運動学・弾道シェーダー注入）** — 山脈崩壊約2,800ブロック・410本（約1,850ブロック）の弾性成長森林・700個の爆煙キノコ雲・1,400片の紙吹雪・900個の天の川星団をすべて `onBeforeCompile` / カスタム頂点シェーダーへ完全オフロード。CPUループ **0回**・毎フレームの行列バッファ転送 **0 bytes** を達成。
2. **Static PBR Voxel Mega-Atlas Single-Draw Merger** — 町（16棟の家・時計台・噴水・市場・街灯）・石橋・狼の断崖・周囲の丘の全13種のPBRテクスチャ（拡散＋バンプ＋発光窓）を1枚の `512×512` メガアトラスへ統合し、静的ワールド全体を **1ドローコール** に圧縮。
3. **Rigid-Subtree Geometry Merger ＋ 4ドローコール王立軍団＆2ドローコール64連オラオラ拳** — TT・旗艦・各キャラの剛体パーツをマテリアル別に結合し、王立軍団22体（旧308ドローコール）を **4ドローコール**、オラオラ連打拳（旧96ドローコール）を **2ドローコール** へ圧縮。
4. **Fused 4-Pass Dual-Kawase HDR Bloom ＋ CAS鮮鋭化パイプライン** — 16パス消費していた標準 `UnrealBloomPass + EffectComposer` を **4パス**（HDR描画 → 1/4輝度抽出 → 1/8 Kawaseボケ → **CAS鮮鋭化＋ブルーム＋色収差＋集中線＋ACES＋sRGB 1パス完全融合**）に置換し、フィルレート負荷を約6.5倍削減。
5. **SmartShadowDirector（適応型フォーカス影キャッシュ）** — カメラ主役周辺72mへシャドウフラスタムを密着させ、1024×1024で従来以上の影精細度を得つつピクセル数を4分の1化、さらに時間的キャッシュ更新で影パス負荷を半減。
6. **Closed-Loop PID動的解像度制御（DRS）＋ Act-Window GPU Sleep** — モバイルGPUの高負荷瞬間に解像度を微調整しつつCASでボクセル輪郭の鮮鋭感を100%維持し、出番外のVFX/群衆/森林は自動でGPUスリープ。

## スマホ横画面・自動全画面・極限ミニマリストUI

- 初回タップで **自動全画面（Fullscreen API）＋横画面ロック（`screen.orientation.lock('landscape')`）** を自動試行。
- 縦向きスマホでは最小限の回転ガイドを表示し、横画面に切り替わると自動で消滅。
- 再生中は字幕以外 **完全UIゼロ** の没入シネマ表示。タップ/マウス移動時のみ極細2pxシークヘアラインと右上5アイコンピルが静かに現れ、2秒後に自動消灯します。

```bash
npm install
npm run dev
npm run build
```
